### RUN
0. If install in conda environment,
```
conda activate comfyenv
```
1. CD into ComfyUI folder (where install is) and run the python script
```
cd ComfyUI
python main.py
```
2. Go to url shown in CLI, usually:
```
To see the GUI go to: http://127.0.0.1:8188
```
